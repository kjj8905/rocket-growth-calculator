# MVP5 - Mobile-First Step Flow

## Route

- Local: `http://localhost:4176/mvp/5`
- Production: `https://wingcoupang.site/mvp/5`

## Body Class

- `mvp-variant-active`
- `mvp-theme-5`

## Role

MVP5 explores a mobile-first single-column calculator experience. It prioritizes one-hand reading and result-first progression.

## Structure

- Narrow centered app shell on desktop
- Navigation as compact grid
- Horizontal scrolling stage banners on home
- Stage view uses one column
- Result/preview panel appears before the input form

## Design Intent

Mobile-first seller tool. This version is useful if most users open the calculator while checking quotes or invoices on a phone.

## Current Checks

- Real calculator fields are preserved.
- Save button remains available.
- Result panel is ordered before form panel in stage view.
- Community and search trend links remain available.

## Watchouts

Because MVP5 is single-column, long result panels can push inputs down. If selected as the main direction, reduce result panel density or add sticky step controls.

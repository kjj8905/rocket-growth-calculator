# Sellerdit 사용자 플로우 & 와이어프레임 기준

업데이트: 2026-06-29

## 목적

셀러딧 커뮤니티의 현재 MVP UI/UX 기준을 고정한다. 이후 수정 시 이 문서를 먼저 참고해 헤더, 피드, 상세, 프로필, 저장 플로우가 흔들리지 않게 한다.

## 공통 구조

### 전역 헤더

모든 셀러딧 화면에서 같은 헤더를 사용한다.

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ S 셀러딧                 [        커뮤니티 검색        ]  계산기 검색트렌드 셀러딧  💬 +만들기 🔔 프로필 │
└──────────────────────────────────────────────────────────────────────────────┘
```

- 왼쪽: 셀러딧 브랜드
- 중앙: 커뮤니티 검색창
- 오른쪽: 로켓그로스 계산기 / 검색트렌드 / 셀러딧 wordmark / 액션
- 헤더는 페이지 내부 요소가 아니라 전역 헤더로 취급한다.
- `/community`, 글 상세, 공급처, 프로필, 저장한 글에서 동일한 위치와 크기를 유지한다.

### 데스크톱 레이아웃

```text
┌───────────────┬──────────────────────────────────────────┬──────────────────┐
│ 왼쪽 레일     │ 피드/본문                                  │ 오른쪽 인기글     │
│ fixed         │ 최대 약 700px, 1024px에서는 자동 축소       │ 약 300px          │
└───────────────┴──────────────────────────────────────────┴──────────────────┘
```

- 왼쪽 레일은 PC에서 화면 맨왼쪽 고정.
- 오른쪽 인기게시물 rail은 PC에서 유지.
- 피드/본문 폭은 기존보다 약간 넓게 잡되, 1024px에서는 가로 스크롤이 생기지 않게 자동 축소.

### 모바일 레이아웃

```text
┌──────────────────────────────┐
│ ☰  셀러딧                 프로필 │
│ [       커뮤니티 검색       ] │
├──────────────────────────────┤
│ 피드/본문 단일 컬럼          │
└──────────────────────────────┘
```

- 좌우 rail 숨김.
- 단일 컬럼 피드.
- 하단 탭 유지.
- 프로필/피드/상세 카드 밀도는 앱형 compact 기준.

## 주요 플로우

### 1. 글 탐색

```text
커뮤니티 홈 → 피드 스크롤 → 글 본문/더 보기 클릭 → 상세 페이지
```

- 피드 상단 정렬/카테고리 2줄 필터는 제거한다.
- 탐색은 왼쪽 레일, 검색, 오른쪽 인기게시물, 상세 진입으로 처리한다.
- H1은 SEO/접근성용으로 유지하되 시각적으로 숨김 처리한다.

### 2. 글 작성

```text
+ 만들기 또는 글쓰기 → 글쓰기 모달 → 분류/본문/이미지/태그 입력 → 등록 → 상세 페이지 이동
```

- 작성 CTA는 전역 헤더/모바일 하단 탭에서 접근.
- 작성 완료 후 `/community/:slug`로 이동.

### 3. 프로필 이동

```text
피드 아바타 클릭 → /u/:handle
피드 작성자명 클릭 → /u/:handle
상세 아바타 클릭 → /u/:handle
헤더 프로필 클릭 → 내 프로필 또는 로그인
```

- 아바타와 작성자명은 동일한 공개 프로필로 연결한다.
- 아바타는 링크임을 hover/focus로 표시한다.

### 4. 저장하기

```text
게시글 하단 북마크 클릭 → /api/community/reactions(type=bookmark) → 상태/토스트 표시 → /community/saved에서 확인
```

- 로그인 상태: 즉시 active 상태와 토스트 표시.
- 비로그인 상태: 토스트로 로그인 필요 안내 후 로그인으로 이동.
- 아이콘 DOM은 유지하고 `is-active`, `aria-pressed`만 변경한다.

### 5. 좋아요/댓글/공유

```text
좋아요 클릭 → count/active 변경
댓글 클릭 → 상세 댓글 영역 이동
공유 클릭 → URL 복사 + 토스트
```

- 아이콘형 버튼은 텍스트로 치환하지 않는다.
- 피드백은 toast/status로 제공한다.

### 6. 프로필 화면

```text
/u/:handle → compact profile card → 게시물/댓글/저장한 글/좋아요/소개 탭
```

- 커버형 대형 헤더 금지.
- 흰색 compact card 기준.
- 모바일은 430/390/360/320에서 동일 밀도 유지.

## SEO/노출 구조 기준

- 각 대표 페이지는 고유 title/description/canonical 유지.
- 시각적으로 제거한 피드 필터 대신 H1은 `sellerdit-visually-hidden`으로 유지.
- 글 상세는 QAPage/Article JSON-LD 유지.
- 작성자 링크 `/u/:handle`을 실제 내부 링크로 제공.
- 저장/좋아요 같은 개인화 액션은 SEO 필수 콘텐츠가 아니며 버튼 상태만 클라이언트에서 변경.
- sitemap/robots와 canonical 충돌 여부는 배포 시 함께 검수한다.

## 검수 매트릭스

필수 뷰포트:

```text
1920, 1440, 1280, 1100, 1024, 430, 390, 360, 320
```

필수 페이지:

```text
/community
/community/today-logistics-fee-question
/community/suppliers
/u/도매꾹탐색가
/community/saved
```

필수 상호작용:

```text
아바타 클릭 → 프로필 이동
북마크 클릭 → 상태/토스트 변화
공유 클릭 → URL 복사 토스트
좋아요 클릭 → count/active 변화
헤더 검색/우측 nav 겹침 없음
```

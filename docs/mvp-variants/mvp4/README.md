# MVP4 - Dark Operations Console

## Route

- Local: `http://localhost:4176/mvp/4`
- Production: `https://wingcoupang.site/mvp/4`

## Body Class

- `mvp-variant-active`
- `mvp-theme-4`

## Role

MVP4 explores a dark operations-console layout. It keeps community navigation on the left and turns the calculator into a denser working console.

## Structure

- Dark theme
- Left navigation rail
- Stage selection rail inside calculator workspace
- Input form in the middle
- Result panel on the right
- Two-column field grids collapse to one column to keep readability in the tighter center panel

## Design Intent

Operator console for sellers comparing invoices, quotes, and costs. This version is the most "different company" visually and structurally.

## Current Checks

- Real calculator fields are preserved.
- Stage form and save button remain present.
- No horizontal overflow in desktop check.
- Community and search trend links remain available.

## Watchouts

Dark mode creates contrast and readability risk. Any new muted text, disabled fields, or validation messages should be checked visually.

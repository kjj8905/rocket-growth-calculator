# MVP1 - Canonical Calculator

## Route

- Local: `http://localhost:4176/`
- Production: `https://wingcoupang.site/`

## Role

MVP1 is the current canonical Rocket Growth calculator experience. It is the baseline for function, wording, calculation behavior, and public indexing.

## Structure

- Top title and account area
- Main navigation
- Simplified home calculation criteria block
- Five-stage calculator banners
- Calculator workspace after stage selection
- Community and guide links

## Design Intent

Plain, practical, Toss-like blue and white product UI. It should feel safest and closest to the original product direction.

## Must Keep

- Five-stage calculator
- Final cost and margin summary
- Calculator save button behavior
- Community entry points
- Guide links for SEO/GEO

## Notes For Next AI

Treat MVP1 as the functional source of truth. If a formula works in MVP1 but breaks in another MVP route, the variant CSS or injected route is probably at fault, not the formula.
